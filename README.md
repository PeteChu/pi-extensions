# ✨ pi-extensions

A collection of handy [pi](https://github.com/earendil-works/pi-coding-agent) extensions by [@petechu](https://github.com/petechu).

_⚠️ These extensions were built through vibecoding. Use at your own risk._

---

## 🤖 ai-commit — `/commit`

> Generate Conventional Commit messages from staged changes — review, edit, or regenerate, then commit.

```bash
pi install npm:@petechu/pi-ai-commit
```

## 💬 answer — `/answer`

> Extract questions from the last assistant message, answer them in an interactive TUI, and send responses back to the chat.

```bash
pi install npm:@petechu/pi-answer-studio
```

## 🔌 extension-toggle — `/extension-toggle`

> Enable or disable installed pi extensions, skills, prompts, and themes — browse, toggle with space, reload to apply.

```bash
pi install npm:@petechu/pi-extension-toggle
```

## 📚 code-wiki — `/code-wiki`

> **⚠️ Beta — Highly Experimental**
> Generate and maintain a persistent codebase wiki — init, update, and query documentation that compounds over time.

```bash
pi install npm:@petechu/pi-code-wiki
```

## 📊 package-usage — `/package-usage`

> Passively collected usage statistics for installed Pi packages. See which tools and skills earn their place in your workflow.

```bash
pi install npm:@petechu/pi-package-usage
```
